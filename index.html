Retos JavaScript — Cargador único

Cómo usar: este archivo carga un reto a la vez.
Solo debes cambiar manualmente el src de la etiqueta <script id="reto"> al nombre del archivo JS del reto que quieras probar.

Ejemplos de archivos JS válidos (colócalos en la misma carpeta):

  • arkanus.js — El códice de Arkanus
  • comprometidos.js — Archivos comprometidos
  • plagio.js — Frases plagiadas
  • frutas.js — Frutas envasadas
  • habilidades.js — Habilidades compatibles
  • portal.js — Puertas del portal temporal
  • anagramas.js — Anagramas

Los scripts pedirán datos con prompt y mostrarán resultados en alert y consola (F12).

Tip trainer favorito : si al abrir la página no ves prompts, revisa la consola del navegador (F12) por errores de ruta o nombre del archivo.
